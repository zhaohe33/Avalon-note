# 圆桌档案

在一个输入框内填写 5 至 10 个名字，每行一个。圆桌按名单顺序排列，可以选中座位并交换相邻玩家。进入圆桌后点任意玩家头像开始录音。点另一位会结束上一段，显示摘要并尝试开始录下一位。也可以点「结束这段发言」，等选好下一个发言人再录。

发言摘要使用浏览器内的句子提取，无需账号或 API 密钥。语音识别由浏览器提供，需要麦克风权限，浏览器可能使用其在线识别服务。

## GitHub Pages

将本目录里的文件推到仓库的 `main` 分支。在 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)**，保存后从同一页面查看站点链接。
