# 圆桌档案

阿瓦隆发言工作台。按轮次记录、编辑发言，用「下一位」按座位切换玩家。支持浏览器语音识别时，可以选定玩家后用麦克风录入。

点「复制发言与总结提示词」，再用「打开 ChatGPT」进入自己的账号，粘贴并发送，即可生成逐人摘要。网站无需 API 密钥。发言保存在当前浏览器，不随 ChatGPT 账号跨设备同步，也不写入 GitHub 仓库。

## GitHub Pages

将本目录里的文件推到 GitHub 仓库的 `main` 分支。进入仓库的 **Settings → Pages**，把 **Source** 设置为 **Deploy from a branch**，选择 **main** 和 **/ (root)**，然后保存。部署完成后，Pages 设置页会显示访问链接。

访问 GitHub Pages 链接即可使用。语音录入取决于浏览器支持和麦克风权限。
