# 圆桌档案

在一个输入框内填写 5 至 10 个名字，每行一个。圆桌按名单顺序排列，可以选中座位并交换相邻玩家。进入圆桌后点头像选首位，再按「开始发言」。开录后选择顺时针或逆时针，按「下一位」即可显示上一段摘要并切换；也可点其他头像直接切换。也可以点「结束这段发言」，等选好下一个发言人再录。

网页按人数显示默认板子和任务人数，可在开局前加入莫德雷德或奥伯伦，占用邪恶阵营的空位。发言摘要在浏览器内归纳明确的组队建议、立场和角色自称。可复制板子和摘要到 ChatGPT 做进一步分析，无需 API 密钥。语音识别由浏览器提供，需要麦克风权限，浏览器可能使用其在线识别服务。

## GitHub Pages

将本目录里的文件推到仓库的 `main` 分支。在 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)**，保存后从同一页面查看站点链接。
